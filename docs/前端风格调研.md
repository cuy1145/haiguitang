## 一、现在真正在用的风格家族（2024–2026）

| # | 风格 | 一句话特征 | 被点名的真实例子 | 对「海龟汤」的适配 |
|---|---|---|---|---|
| 1 | **Bento Grid 便当格** | 非对称格子、大小卡混排、紧凑沟槽 + 大方内边距，用"块的大小"表达层级 | Apple、Linear、Vercel | ⭐⭐⭐ 把「深度/声呐/汤面/回响」做成格子，信息密度高又不乱 |
| 2 | **Refined Glassmorphism 精炼毛玻璃** | 2024+ 的收敛版：`blur(8px)` + 1px 亮边 + 低透明度，而不是 2021 那种 `blur(20px)` + 白 10% | Apple、Linear、Stripe | ⭐⭐⭐ 弹窗/浮层/仪表盘底板直接用 |
| 3 | **Neobrutalism 新粗野** | 2–4px 纯黑硬边 + **无模糊硬阴影** + 高对比撞色，粗糙但真诚 | Gumroad、Figma 市场页 | ⭐⭐ 太吵，但适合做"卷宗/档案"版 |
| 4 | **Dark Mode First 深色优先** | 深色是默认、浅色是备选；配色全部 token 化 + `color-scheme` | Vercel、Linear、GitHub | ⭐⭐⭐ 我的深海版已在用 |
| 5 | **Editorial / Neo-Swiss 编辑排版** | 巨大字级、严格网格、单一强调色；衬线做标题 + 无衬线做正文 | 见各图库的 "editorial/typography" 分区 | ⭐⭐⭐ 汤面用大号衬线，天然像印出来的题卡 |
| 6 | **Cozy / Storybook 温暖故事书（Ghibli 感）** | 暖棕/琥珀底色、蚀刻排线插画、圆润玩具感图标、木牌与纸张质感；行业观察称之为 "comfort gaming"（世界越做越暖、越软、越社交） | Ghibli 风格模板/组件库、以及你在样例里发的「深海汤屋」 | ⭐⭐⭐ **和你的样例同一条脉络** |
| 7 | **Soft Maximalism 软性极繁 / 扁平插画** | 大色块 + 重复图案纹理 + 手绘元素，情绪优先于克制 | Duolingo、Headspace 一类消费产品 | ⭐⭐ 做"汤屋"的插画层很合适 |
| 8 | **Y2K / Retro-futurism 与 CRT 终端** | 复古屏幕、扫描线、荧光绿/琥珀单色、机械仪表 | Poolsuite 一类氛围站 | ⭐⭐ 可当"老式声呐仪"彩蛋 |
| 9 | **Kinetic Typography + Micro-interactions 动效排版/微交互** | 文字入场、滚动揭示、可变字重；动效 ≤300ms、尊重 `prefers-reduced-motion` | Stripe、Linear、Vercel | ⭐⭐⭐ 恰好用在"回声/破水"两个关键反馈 |
| 10 | **Spatial / Z-depth 空间化** | 有纵深与透视的层级，为空间计算设备铺路 | Apple 的 vision 系页面 | ⭐⭐ 用在"下潜/破水"过场 |

## 二、明确已经过时、不要碰的（趋势时间线里的 "Dated"）

- 桌面端汉堡菜单（隐藏导航、可发现性差）
- 轮播 Hero（第一屏之后点击率极低、无障碍差）
- 视差堆叠 overload（性能 + 眩晕 + 无障碍）
- 完全拟物 / 重阴影（`0 10px 30px rgba(0,0,0,.5)` 这种）
- 艳俗渐变、图库英雄图（廉价感）
- 动效 >300ms、无意义的弹跳、视差满屏

## 四、给「海龟汤」的四个可选方向（做完报告后你挑一个，我就动手）

1. **汤屋 · 温暖故事书**（对齐你给的样例）：暖棕/琥珀底、蚀刻排线纹理、木牌边框、圆润玩具感图标；布局 = 左「问答记录」＋中央「欢迎/题面」＋右「线索板」。质感用 CSS 渐变与 SVG 噪点（data URI 内联）做，不引外部图片与字体。
2. **深海声呐**（已完成，`/deep/`）：冷色仪器台、声呐环、气瓶倒计时、破水公示。
3. **卷宗 / 新粗野**：纸黄底 + 红章 + 2–4px 硬边 + 无模糊硬阴影，像侦查档案；题面做成"案卷首页"。
4. **Bento + 编辑排版**：现代扁平、非对称格子、大号衬线标题 + 单一强调色；最"当代"，但情绪最冷。

**实现约束（三套都得守）**：单文件、零依赖、不引外链图片/字体（selfcheck 会拦）、手机优先、动效尊重 `prefers-reduced-motion`。
